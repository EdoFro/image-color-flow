This document records decisions and proposals for future versions. The features described here are not implemented yet.

## New project and preferences

- Add “New project” to start without images and with default parameters, protecting unsaved changes.
- Allow users to customize default values in Preferences.
- Add an **“On opening the editor”** preference, with **“Load example”** and **“Empty project”** options.
- **The factory setting will be “Load example”.** The example introduces the tool to first-time users. This preference will be stored locally in the browser.
- “New project” will always create an empty project; the startup preference will only determine what loads when opening the editor.

## Later: example as a tutorial

Turn the example presentation into an explanatory manual or tutorial showing how the tool works. Keep this idea for a later release; its content and behavior remain to be defined.
