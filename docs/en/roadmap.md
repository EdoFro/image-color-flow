## New project and preferences · implemented in 0.14.0

- “New project” is available to start without images and with default parameters, protecting unsaved changes.
- Users can customize default values in Preferences.
- Available: an **“On opening the editor”** preference, with **“Load example”** and **“Empty project”** options.
- **The factory setting is “Load example”.** The example introduces the tool to first-time users. This preference is stored locally in the browser.
- “New project” always creates an empty project; the startup preference only determines what loads when opening the editor.

See the [user guide](user-guide.md#new-project-and-preferences).
