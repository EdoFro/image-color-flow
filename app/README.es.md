# Tinta y color · Editor portable

[English](README.md) | **Español**

Abre [index.html](index.html) en Chrome o Edge. Conserva completa esta carpeta `app/` al trasladarla. No requiere instalación, servidor ni conexión; el ejemplo introductorio está incluido.

1. Prueba el ejemplo o pulsa **Nuevo proyecto** para empezar con un lienzo vacío.
2. **Cargar imágenes** abre los controles de imagen coloreada e inicial opcional. Genera y revisa una base si partes sólo de la coloreada.
3. Añade etapas, puntos, zonas y recorridos. Define enfoque y destacados, y reproduce.
4. **Guardar proyecto** descarga el `.colorflow.json` editable; **Exportar HTML** genera una presentación autónoma.
5. **Preferencias** configura el inicio y los predeterminados de proyectos/etapas nuevos. Exporta/importa preferencias para trasladarlas entre navegadores o ubicaciones.

La interfaz está disponible en español, inglés, francés y alemán. El selector recuerda el idioma en este navegador. El ejemplo se carga por defecto; Preferencias permite iniciar vacío. Nuevo/Abrir/recargar ejemplo protegen cambios sin guardar. Descargar desde la advertencia conserva el proyecto hasta que confirmes el reemplazo.

Las presentaciones exportadas funcionan sin esta carpeta. Clic en la imagen inicia/avanza; Espacio pausa/continúa, las flechas cambian etapas y H o el logo pequeño muestran los controles. Al finalizar, el botón de reinicio vuelve a Inicio.

Código y documentación: [MIT](LICENSE). Condiciones de las imágenes de ejemplo: [NOTICE.md](NOTICE.md). El paquete completo añade API local, CLI y MCP; Node.js sólo se necesita para esas herramientas opcionales.

[Manual completo y repositorio](https://github.com/EdoFro/image-color-flow)

## Integrar en una presentación

En Exportar HTML elige **Integrar en otra presentación**. Descomprime el ZIP: incluye animación, controlador, instrucciones y ejemplo. Entrega esa carpeta al agente que prepara la presentación. El contenedor debe conectar su avance al controlador; no basta con insertar la imagen. Conserva el proyecto JSON para seguir editando.
