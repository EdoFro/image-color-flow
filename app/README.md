# Tinta y color · Portable editor

**English** | [Español](README.es.md)

Open [index.html](index.html) in Chrome or Edge. Keep this entire `app/` folder together when moving it. No installation, server or internet connection is required; the introductory example is included.

1. Try the example or choose **New project** to start with an empty canvas.
2. **Load images** opens the colored-image and optional initial-image controls. Generate and review a base when starting from a colored image alone.
3. Add stages, points, regions and brush paths. Set camera framing and highlights, then play.
4. **Save project** downloads editable `.colorflow.json`; **Export HTML** produces a self-contained presentation.
5. **Preferences** configures startup and defaults for new projects/stages. Export/import preferences to transfer them between browsers or locations.

The interface supports English, Spanish, French and German. Its language selector remembers the choice in this browser. The example loads by default; Preferences can choose an empty startup. New/Open/example reload protect unsaved changes. Downloading in the warning does not replace the project until you confirm.

Exported presentations work independently of this folder. Click the image to start/advance, Space to pause/continue, arrows to move between stages, and H or the small logo to show controls. At the end, the visible restart control returns to the initial view.

Code and documentation: [MIT](LICENSE). Example-image conditions: [NOTICE.md](NOTICE.md). The complete package additionally provides the local API, CLI and MCP; Node.js is only needed for those optional tools.
