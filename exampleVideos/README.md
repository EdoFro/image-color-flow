Recordings of animations created with Tinta y color. The [main demonstration, example 6](../README.md#watch-an-animation), is featured on the project home page.

> **Recording quality:** these videos were captured in small windows to keep file sizes down. HTML presentations can display the result at a larger size, depending on source image resolution and project settings.
