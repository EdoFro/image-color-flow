# ImageColorFlow · Editor + local automation

**English** | [Español](README.es.md)

This package includes the portable editor, introductory example, local Node.js API, CLI and MCP server.

- **Editor:** open [app/index.html](app/index.html) in Chrome or Edge. No installation or internet connection is needed. Keep `app/` complete when copying it separately. See [editor instructions](app/README.md).
- **Automation:** Node.js 22 or later; Chrome/Edge/Chromium for image preparation and rendering. No `npm install` is needed. See [API, CLI and MCP setup](AUTOMATION.md).
- **AI assistants:** [workflow guide](docs/en/for-ai.md) and [plan schema](schemas/animation.schema.json).

Run automation commands from this package's root. Keep `automation/`, `schemas/`, `docs/`, `app/` and `package.json` together. Inputs and outputs must stay inside the chosen workspace.
