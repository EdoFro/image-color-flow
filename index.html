Cómo preparar una animación
  1. Carga la imagen coloreada y, si tienes, la inicial.
  2. Delimita una zona con un rectángulo o polígono.
  3. Marca puntos o dibuja un recorrido.
  4. Ajusta la propagación y reproduce.
  5. Guarda tu proyecto y exporta el HTML.

Polígono: clic para añadir vértices, Enter o doble clic para cerrar; Escape cancela. Arrastra los puntos para moverlos. El radio y las velocidades se expresan respecto al ancho de la imagen.

EL PAPEL Y LA TINTA

Preparar las imágenes

La imagen final determina las proporciones. El original se conserva en el proyecto. Generar la base desde la imagen final evita diferencias de alineación. Puedes retirar el pigmento hacia el papel o conservarlo como gris.

Preparar imagen inicial

Conserva la tinta y deja libres las superficies que recibirán color. Genera una propuesta, compárala y ajusta antes de aplicar.
